\section*{Заключение}

В ходе работы выполнен анализ предметной области «Геомониторинг автопарка каршеринга>>, определены цели функционирования базы данных, выявлены сущности и их атрибуты. На основе анализа построены ER-диаграмма и схема базы данных, описаны таблицы с обоснованием типов атрибутов.

Схема реализована в СУБД PostgreSQL. Для заполнения базы данных написан seeder на языке Go с использованием библиотек \textbf{pgx/v5} и \textbf{golang-migrate}. База данных содержит 20~таблиц, в которой хранится 364523 записи. 

Выполнены 9~запросов к базе данных. Для каждого запроса приведены результат выполнения запроса, графический план выполнения, текстовое описание и реляционная формула.

Работа выполнялась на устройстве Apple MacBook Air с процессором Apple~M4 и 16~ГБ оперативной памяти. 
В Docker-контейнере поднимался PostgreSQL 14. Генерация данных реализована на языке Go с использованием библиотек \textbf{pgx/v5} и \textbf{golang-migrate}, визуализация результатов выполнена средствами Python (\textbf{matplotlib}).

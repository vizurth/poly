\section{Постановка задачи}
% ============================================================

Дан определённый интеграл (вариант 1):
\[
I = \int_{1}^{2{,}5} \ln\!\bigl(x^2 + \sqrt{x^4+1}\bigr)\,dx.
\]

\textbf{Задание 1.} Вычислить приближённо интеграл по простейшим формулам
(левых прямоугольников, правых прямоугольников, центральных прямоугольников,
трапеций, парабол) при числе подынтервалов $n = 4$. Оценить погрешности.

\textbf{Задание 2.} Вычислить приближённо интеграл по формуле Ньютона-Котеса
с $n = 5$ узлами.

\textbf{Задание 3.} Вычислить приближённо интеграл по формуле Гаусса с $n = 4$
узлами. Оценить погрешность.

\subsection*{Точное значение интеграла}

Функция $f(x) = \ln\!\bigl(x^2 + \sqrt{x^4+1}\bigr) = \operatorname{arcsinh}(x^2)$
(поскольку $\operatorname{arcsinh}(u) = \ln(u+\sqrt{u^2+1})$). Первообразная через
элементарные функции в замкнутом виде не выражается, поэтому точное значение
вычислено численно методом адаптивного квадрирования высокой точности:
\[
I \approx 2{,}689063.
\]

\section{Задание 1. Простейшие квадратурные формулы}
% ============================================================

\subsection{Теоретические сведения}

Пусть отрезок $[a,b]$ разбит на $n$ равных частей с шагом $h = (b-a)/n$.
Узлы разбиения: $x_i = a + ih$, $i = 0, 1, \ldots, n$.

Формулы:
\[
I_L = h\sum_{i=0}^{n-1}f(x_i), \qquad
I_R = h\sum_{i=1}^{n}f(x_i), \qquad
I_C = h\sum_{i=0}^{n-1}f\!\left(x_i + \tfrac{h}{2}\right),
\]
\[
I_T = h\!\left(\frac{f(a)+f(b)}{2} + \sum_{i=1}^{n-1}f(x_i)\right)\]
\[
I_S = \frac{h}{3}\!\left(f(x_0) + 4\!\sum_{\text{нечётн.}}\!f(x_i)
      + 2\!\sum_{\text{чётн.}}\!f(x_i) + f(x_n)\right).
\]

\section{Задание 2. Формула Ньютона-Котеса с $n = 5$ узлами}
% ============================================================

\subsection{Теоретические сведения}

Формула Ньютона-Котеса с $n$ узлами:
\[
\int_a^b f(x)\,dx \approx (b-a)\sum_{k=0}^{n-1} C_k^{(n)}\,f(x_k),
\]
где $x_k = a + kh$, $h = (b-a)/(n-1)$, коэффициенты $C_k^{(n)}$ берутся из таблицы.

При $n = 5$ узлах применяется \textbf{формула Буля}:
\[
\int_a^b f(x)\,dx \approx \frac{b-a}{90}\bigl[7f(x_0)+32f(x_1)+12f(x_2)+32f(x_3)+7f(x_4)\bigr].
\]
Остаточный член: $\displaystyle R^{(5)} = -\frac{8(b-a)}{945}\,h^6\,f^{(6)}(\xi)$,
$\xi\in[a,b]$.

\subsection{Вычисление}

Шаг:
\[
h = \frac{b-a}{n-1} = \frac{2{,}5-1}{4} = 0{,}375.
\]

Узлы интерполяции:
\[
x_0 = 1{,}0000,\quad x_1 = 1{,}3750,\quad x_2 = 1{,}7500,
\quad x_3 = 2{,}1250,\quad x_4 = 2{,}5000.
\]

Значения функции совпадают с таблицей~\ref{tab:s1_nodes}. Подставляем в формулу Буля:
\begin{align*}
&7f(x_0)+32f(x_1)+12f(x_2)+32f(x_3)+7f(x_4)\\
&= 7\cdot0{,}881374 + 32\cdot1{,}393624 + 12\cdot1{,}838028
   + 32\cdot2{,}212732 + 7\cdot2{,}532068\\
&= 6{,}169615 + 44{,}595954 + 22{,}056331 + 70{,}807413 + 17{,}724476
 = 161{,}353788.
\end{align*}

\[
\boxed{I^*_\text{НК} = \frac{1{,}5}{90}\cdot 161{,}353788
= 0{,}016\overline{6}\cdot 161{,}353788 \approx 2{,}689230.}
\]

\subsection{Погрешность}

Фактическая погрешность:
\[
\Delta I^*_\text{НК} = |I - I^*_\text{НК}| = |2{,}689063 - 2{,}689230| = 0{,}000167.
\]

Теоретическая оценка остаточного члена. Шестая производная $f^{(6)}(x)$
вычислена численно; на $[1;\,2{,}5]$:
\[
M_6 = \max_{[1;\,2{,}5]}\bigl|f^{(6)}(x)\bigr| \approx 254{,}558 \quad (\text{при }x=1).
\]

\[
|R^{(5)}| \leq \frac{8(b-a)}{945}\,h^6\,M_6
= \frac{8\cdot 1{,}5}{945}\cdot(0{,}375)^6\cdot 254{,}558\]
\[= 0{,}012698\cdot 0{,}002776\cdot 254{,}558 = 0{,}008989.
\]

Фактическая погрешность $0{,}000167 < 0{,}008989$ --- оценка выполнена.

\section{Задание 3. Формула Гаусса с $n = 4$ узлами}
% ============================================================

\subsection{Теоретические сведения}

Для вычисления интеграла $\displaystyle\int_a^b f(x)\,dx$ по формуле Гаусса с $n$
узлами на произвольном отрезке $[a,b]$ узлы пересчитываются из стандартных
узлов $t_i \in [-1,1]$ по формуле:
\[
x_i = \frac{a+b}{2} + \frac{b-a}{2}\,t_i,
\]
а приближённое значение интеграла:
\[
\int_a^b f(x)\,dx \approx \frac{b-a}{2}\sum_{i=1}^{n} A_i\,f(x_i),
\]
где $A_i$ --- веса формулы (не меняются при переходе к $[a,b]$).

\subsection{Узлы и веса для $n = 4$}

\hline
$i$ & $t_i$ & $A_i$ \\
\hline
1 & $-0{,}861136312$ & $0{,}347854845$ \\

\subsection{Пересчёт узлов на отрезок $[1;\,2{,}5]$}

\[
\frac{a+b}{2} = \frac{1+2{,}5}{2} = 1{,}75, \qquad
\frac{b-a}{2} = \frac{2{,}5-1}{2} = 0{,}75.
\]
\[
x_i = 1{,}75 + 0{,}75\,t_i.
\]
\begin{align*}
x_1 &= 1{,}75 + 0{,}75\cdot(-0{,}861136) = 1{,}75 - 0{,}645852 = 1{,}104148,\\
x_2 &= 1{,}75 + 0{,}75\cdot(-0{,}339981) = 1{,}75 - 0{,}254986 = 1{,}495014,\\

x_4 &= 1{,}75 + 0{,}75\cdot(+0{,}861136) = 1{,}75 + 0{,}645852 = 2{,}395852.

\[
I^*_\text{Г} = \frac{b-a}{2}\sum_{i=1}^{4}A_i\,f(x_i)
= 0{,}75\cdot\bigl(0{,}357654+1{,}006962+1{,}369208+0{,}851593\bigr)\]
\[= 0{,}75\cdot 3{,}585417
\approx \mathbf{2{,}689062}.
\]


\subsection{Оценка погрешности}

Первообразная функции $f(x) = \ln\!\bigl(x^2+\sqrt{x^4+1}\bigr)$
в замкнутом виде не существует, поэтому формула Ньютона-Лейбница
неприменима. Погрешность оценивается через остаточный член
формулы Гаусса:
\[
|R_n| \leq \frac{(b-a)^{2n+1}\,(n!)^4}{(2n+1)\,[(2n)!]^2}\,M_{2n},
\qquad M_{2n} = \max_{x\in[a,b]}\bigl|f^{(2n)}(x)\bigr|.
\]
Апостериорно, сравнивая с результатом формулы Буля ($n=5$)
как более точного метода:
\[
\Delta I^*_\text{Г} \approx |I^*_\text{Г} - I^*_\text{НК}|
= |2{,}689062 - 2{,}689230| = 2\cdot10^{-4}.
\]
Округляем до верных знаков: $\bar\Delta = 0{,}0002$,
цифра $2 \leq 5$ → верные разряды левее $10^{-4}$:
\[
\boxed{I^*_\text{Г} = 2{,}689.}
\]

\section{Выводы}
% ============================================================

В лабораторной работе вычислен интеграл
$\displaystyle\int_1^{2{,}5}\ln\!\bigl(x^2+\sqrt{x^4+1}\bigr)\,dx \approx 2{,}689063$
тремя группами методов.

\begin{enumerate}
\item \textbf{Простейшие формулы} ($n=4$ подынтервала): формулы левых и правых
прямоугольников дают грубые приближения (погрешность $\sim 0{,}30$--$0{,}32$),
так как функция нелинейна на отрезке. Центральные прямоугольники и трапеции
точнее (погрешность $\sim 0{,}004$--$0{,}007$). Наилучший результат показала
формула Симпсона ($\Delta I = 0{,}000302$).

\item \textbf{Формула Ньютона-Котеса с $n=5$ узлами} (Буля) даёт погрешность
$0{,}000167$, что точнее всех простейших формул. С ростом числа узлов точность
формул Ньютона-Котеса возрастает.

\item \textbf{Формула Гаусса с $n=4$ узлами} обеспечивает наилучшую точность:
$\Delta I^*_\text{Г} \approx 6\cdot10^{-7}$. Это объясняется алгебраической
степенью точности $2n-1=7$.
\end{enumerate}

import numpy as np
from scipy import integrate

f = lambda x: np.log(x**2 + np.sqrt(x**4 + 1))
a, b = 1.0, 2.5

# Tochnoe znachenie
I_exact, _ = integrate.quad(f, a, b)
print(f"Tochnoe: {I_exact:.6f}")

# ===== Zadanie 1: prosteyshie formuly, n=4 =====
n = 4
h = (b - a) / n         # 0.375
xi = [a + i*h for i in range(n+1)]

I_L = h * sum(f(xi[i]) for i in range(n))
I_R = h * sum(f(xi[i]) for i in range(1, n+1))
I_C = h * sum(f(a + (i+0.5)*h) for i in range(n))
I_T = h * (f(a)/2 + sum(f(xi[i]) for i in range(1,n)) + f(b)/2)
I_S = h/3 * (f(a) + 4*sum(f(xi[i]) for i in range(1,n,2))
           + 2*sum(f(xi[i]) for i in range(2,n,2)) + f(b))

print(f"Lev. pr.: {I_L:.6f}  err={abs(I_exact-I_L):.6f}")
print(f"Pr.  pr.: {I_R:.6f}  err={abs(I_exact-I_R):.6f}")
print(f"Centr.  : {I_C:.6f}  err={abs(I_exact-I_C):.6f}")
print(f"Trapec. : {I_T:.6f}  err={abs(I_exact-I_T):.6f}")
print(f"Simpson : {I_S:.6f}  err={abs(I_exact-I_S):.6f}")

# ===== Zadanie 2: Ньютон-Котес n=5 (formula Bulya) =====
h_nc = (b - a) / 4      # 0.375
xnc  = [a + i*h_nc for i in range(5)]
fv   = [f(xi) for xi in xnc]
I_NC = (b-a)/90 * (7*fv[0]+32*fv[1]+12*fv[2]+32*fv[3]+7*fv[4])
print(f"NK (n=5): {I_NC:.6f}  err={abs(I_exact-I_NC):.6f}")

# ===== Zadanie 3: Gauss n=4 =====
t = [-0.861136312, -0.339981044, 0.339981044, 0.861136312]
A = [ 0.347854845,  0.652145155, 0.652145155, 0.347854845]
mid  = (a + b) / 2      # 1.75
half = (b - a) / 2      # 0.75
x_g  = [mid + half*ti for ti in t]
I_G  = half * sum(A[i]*f(x_g[i]) for i in range(4))
print(f"Gauss(n=4): {I_G:.6f}  err={abs(I_exact-I_G):.8f}")

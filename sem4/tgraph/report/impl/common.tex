\section{Особенности реализации}

Проект собирается через CMake. Точка входа~-- единый исполняемый файл
с консольным меню. Все модули лабораторных зависят только от \texttt{common};
\texttt{common} ничего не знает про лабораторные.

Пользователь выбирает пункт меню, \texttt{main.cpp} вызывает нужный метод
\texttt{LabXUI}, который читает параметры, запускает алгоритм и выводит
результат в консоль.

\subsection{Модуль common}

Модуль содержит реализацию графа, генератор случайных чисел по
распределению Вейбулла и генератор графов. Он используется всеми
лабораторными для переиспользования кода.

\subsubsection{Graph\textless T\textgreater: хранение графа}

\textbf{Вход:} число вершин \texttt{n}; рёбра добавляются через
\texttt{addEdge(from, to, weight)}.

\textbf{Выход:} матрицы смежности и весов, методы обхода (BFS, DFS)
и вычисления метрик.

\textbf{Описание:} \texttt{Graph<T>}~-- шаблонный класс; тип весов рёбер
задаётся параметром \texttt{T}. Граф хранится в двух матрицах размера
$n \times n$: \texttt{adjMatrix[i][j] = 1} означает наличие ребра $(i,j)$,
\texttt{weightMatrix[i][j]} хранит его вес.

\begin{lstlisting}[style=cstyle, caption={Объявление Graph (graph.h)}]
template <typename T>
class Graph {
  private:
    int numVertices;
    vector<vector<int>> adjMatrix;
    vector<vector<T>> weightMatrix;
  public:
    Graph(int n);
    void addEdge(int from, int to, T weight);
    bool hasEdge(int from, int to) const;
    T getEdge(int from, int to) const;
    int getNumVertices() const;
    vector<vector<int>> getAdjMatrix() const;
    vector<vector<T>> getWeightMatrix() const;
    Graph<T> reorder(const vector<int>& order) const;
    // ...
};
\end{lstlisting}

Также реализованы BFS и DFS внутри класса, методы подсчёта эксцентриситетов
и метод \texttt{reorder(order)}, который перестраивает граф по новому порядку
вершин~-- используется для вывода матрицы после алгоритма Фалкерсона.

\textbf{Сложность:} проверка ребра и доступ к весу~-- $O(1)$;
BFS по матрице~-- $O(V^2)$; память~-- $O(V^2)$.

\subsubsection{WeibullDistribution: генерация случайных чисел}

\textbf{Вход:} параметры масштаба $a$ и формы $c$ (по умолчанию $a=1, c=0.2$).

\textbf{Выход:} случайное число $X > 0$ по распределению Вейбулла.

\textbf{Описание:} Класс хранит параметры и равномерный генератор
\texttt{std::mt19937}. Метод \texttt{generate()} берёт $u \in (0,1)$
и считает $X = a \cdot (-\ln u)^{1/c}$.
Модуль нужен, чтобы результат был положительным.

\begin{lstlisting}[style=cstyle, caption={Генерация числа по распределению Вейбулла (weibull.cpp)}]
double WeibullDistribution::generate() {
    double u = distribution(generator);
    double raw = a * std::pow(-std::log(u), 1.0 / c);
    return (raw > 0) ? raw : -raw;
}
\end{lstlisting}

\textbf{Сложность:} $O(1)$ на одну генерацию.

\subsubsection{Generator\textless T\textgreater: генерация графов}

\textbf{Вход:} число вершин, тип ориентированности, тип знака весов,
параметры двух распределений Вейбулла (для структуры и для весов).

\textbf{Выход:} \texttt{Graph<T>}~-- связный ациклический граф.

\textbf{Описание:} \texttt{Generator<T>} держит два объекта
\texttt{WeibullDistribution}: для структуры графа и для весов рёбер.
Метод \texttt{generateGraph()} строит граф в два прохода.

В первом проходе строится остовное дерево: вершина $i$ соединяется
с одной из вершин $\{0, \ldots, i-1\}$~-- это гарантирует связность
и ациклическость.
Во втором проходе для каждой вершины с оставшимся бюджетом степени
берутся все вершины $j > i$, у которых ещё нет ребра от $i$.
Список перемешивается через \texttt{weibullShuffle} и добавляются
первые $d_i$ рёбер.

\begin{lstlisting}[style=cstyle, caption={Генератор весов и Вейбуллово перемешивание (generator.cpp)}]
template <typename T>
T Generator<T>::generateWeight(WeightType weightType) {
    double weight = distributionForWeights.generate();
    if (weightType == WeightType::NEGATIVE)
        return static_cast<T>(-weight);
    else if (weightType == WeightType::MIXED)
        return isNegative() ? static_cast<T>(-weight)
                            : static_cast<T>(weight);
    return static_cast<T>(weight);
}

template <typename T>
void Generator<T>::weibullShuffle(vector<int>& vertices) {
    int n = vertices.size();
    for (int i = n - 1; i > 0; i--) {
        int j = randomIndex(i + 1);
        swap(vertices[i], vertices[j]);
    }
}
\end{lstlisting}

\textbf{Сложность:} $O(V^2)$ по времени; $O(V^2)$ по памяти.

# ЛАБОРАТОРНАЯ РАБОТА № 1 — Генерация DAG и алгоритм Шимбелла

## Структура проекта:

- `/common/graph` — шаблонный класс `Graph<T>` и генератор DAG
- `/common/distributions` — нормальное распределение для генерации весов рёбер
- `/lab1` — точка входа, UI, реализация алгоритма Шимбелла и подсчёта маршрутов

## Задание 1(DONE): Генерация связного ациклического графа (DAG)

**Цель:** Сформировать случайным образом связный ациклический ориентированный граф (DAG - Directed Acyclic Graph).

**Требования:**

- Пользователь вводит количество вершин N
- Использовать **нормальное распределение** для генерации весов рёбер
- Параметры распределения задать как константы:
  - Среднее значение (μ) = 10.0
  - Стандартное отклонение (σ) = 3.0
- Граф должен быть:
  - Связным (есть путь между любыми двумя вершинами)
  - Ациклическим (нет циклов)
  - Ориентированным (рёбра имеют направление)
- Веса рёбер — положительные вещественные числа

**Реализация:**

- Шаблонный класс `Graph<T>` в `/common/graph/graph.h` (T может быть double, int)
- Генератор DAG в `/common/graph/dag_generator.h`
- Нормальное распределение в `/common/distributions/normal.h`

**Вывод:**

- Матрица смежности (adjacency matrix)
- Список рёбер с весами


## Задание 2: Метод Шимбелла

**Цель:** Реализовать алгоритм Шимбелла для нахождения кратчайших путей фиксированной длины.

**Требования:**

- Пользователь вводит количество рёбер K (длина пути)
- K — это количество рёбер в пути, не количество вершин
- Использовать весовую матрицу сгенерированного графа
- Вычислить две матрицы:
  1. **Минимальные пути** длины K рёбер (shortest paths with exactly K edges)
  2. **Максимальные пути** длины K рёбер (longest paths with exactly K edges)

**Алгоритм Шимбелла:**

```
D^(0)[i][j] = adjMatrix[i][j] (начальная матрица весов)
D^(k)[i][j] = min/max по всем p: D^(k-1)[i][p] + adjMatrix[p][j]
```

**Вывод:**

- Матрица минимальных путей длины K
- Матрица максимальных путей длины K
- Для каждой пары вершин (i, j) показать:
  - Минимальный вес пути из i в j через K рёбер
  - Максимальный вес пути из i в j через K рёбер

## Задание 3: Подсчёт маршрутов между вершинами

**Цель:** Определить все возможные маршруты между двумя заданными вершинами.

**Требования:**

- Пользователь вводит начальную вершину S и конечную вершину T
- Найти все маршруты от S до T (backtracking)
- Подсчитать количество различных маршрутов
- Маршрут — последовательность вершин, где каждая следующая вершина достижима по ребру

**Метод решения:**

- Использовать backtracking (рекурсивный перебор с возвратом)
- Отмечать посещённые вершины чтобы избежать циклов
- Сохранять все найденные пути

**Вывод:**

- Ответ: "Существует маршрут: ДА/НЕТ"
- Количество различных маршрутов
- Список всех найденных маршрутов (последовательности вершин)

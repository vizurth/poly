## 1. Алгоритм Краскала (минимальный остов)

### Псевдокод

```
Вход:  список E рёбер графа G с длинами, упорядоченный в порядке возрастания длин.
Выход: множество T рёбер кратчайшего остова.

  T := ∅
  k := 1  { номер рассматриваемого ребра }
  for i from 1 to p - 1 do
    while z(T + E[k]) > 0 do
      k := k + 1  { пропустить это ребро }
    end while
    T := T + E[k]  { добавить это ребро в SST }
    k := k + 1  { и исключить его из рассмотрения }
  end for
```

> `z(T + E[k]) > 0` — условие того, что добавление ребра E[k] создаёт цикл (т.е. обе вершины ребра уже в одной компоненте связности). `p` — число вершин графа.

## 2. Код Прюфера (кодирование и декодирование остова)

### Кодирование

```
Вход:  Дерево T(V, E) в любом представлении, вершины дерева занумерованы
       числами 1..p произвольным образом.
Выход: Массив A : array [1..p-1] of 1..p — код Прюфера дерева T.

  for i from 1 to p - 1 do
    v := min {k ∈ V | d(k) = 1}  { выбираем вершину v — висячую вершину с
                                    наименьшим номером }
    A[i] := Γ(v)  { запишем в код номер единственной вершины, смежной с v }
    V := V - v    { удаляем вершину v из дерева }
  end for
```

> Для сохранения весов при кодировании: вместе с `A[i]` сохранять вес ребра `(v, Γ(v))` в параллельный массив `W[i]`.

### Декодирование

```
Вход:  Массив A : array [1..p-1] of 1..p — код Прюфера дерева T.
Выход: Дерево T(V, E), заданное множеством рёбер E, вершины дерева
       занумерованы числами 1..p.

  E := ∅  { в начале множество рёбер пусто }
  B := 1..p  { множество неиспользованных номеров вершин }
  for i from 1 to p - 1 do
    v := min {k ∈ B | ∀j ≥ i (k ≠ A[j])}  { выбираем вершину v — неиспользован-
         ную вершину с наименьшим номером, который не встречается в остатке кода
         Прюфера }
    E := E + (v, A[i])  { добавляем ребро (v, A[i]) }
    B := B - v  { удаляем вершину v из списка неиспользованных }
  end for
```

## 3. Максимальное независимое множество вершин (поиск с возвратами)

### Постановка задачи

Найти наибольшее множество вершин **X ⊆ V**, такое что ни одно ребро графа не соединяет две вершины из X, то есть:
```
∀ u, v ∈ X : (u, v) ∉ E
```

### Алгоритм: поиск с возвратами (Backtracking)

```
MAIN:
  m := 0       // размер наилучшего найденного множества
  X := ∅       // наилучшее независимое множество
  BT(∅, V)     // запуск рекурсии

BT(S, T):
  // S — текущее независимое множество
  // T — вершины, которые ещё можно добавить
  if T = ∅:
    if |S| > m:
      m := |S|
      X := S
    return

  for v ∈ T:
    if IS_INDEPENDENT(S, v):          // v не смежна ни с одной вершиной из S
      BT(S ∪ {v}, T \ (Γ*(v)))       // Γ*(v) = {v} ∪ соседи v
    T := T \ {v}                       // не рассматривать v повторно

IS_INDEPENDENT(S, v):
  for u ∈ S:
    if (u, v) ∈ E: return false
  return true
```

> `Γ*(v)` — замкнутое окрестное множество вершины v (сама v + все её соседи).

\section*{3. Цели, задачи и исходные данные}

\addcontentsline{toc}{subsection}{3.1. Цель работы}
\subsection*{3.1. Цель работы}

Целью работы является разработка консольного приложения на языке Haskell для анализа статистики игроков и матчей Национальной баскетбольной ассоциации (НБА) за период 2010--2024 годов. Приложение обеспечивает загрузку данных из CSV-файлов, вычисление аналитических показателей эффективности игроков и команд, а также формирование текстовых отчётов.

\addcontentsline{toc}{subsection}{3.2. Задачи}
\subsection*{3.2. Задачи}

В процессе выполнения работы требуется решить следующие задачи:

\begin{enumerate}
    \item Изучить предметную область спортивной аналитики НБА и форматы представления статистических данных.
    \item Разработать техническое задание, определить структуру данных и архитектуру проекта.
    \item Реализовать модуль чтения и валидации CSV-файлов со статистикой игроков и результатами матчей.
    \item Реализовать математические функции: среднее, медиана, стандартное отклонение, рейтинг эффективности игрока (PER), коэффициент Пифагора для команд, нормализация показателей.
    \item Разработать консольный интерфейс с меню навигации и фильтрацией данных по сезону, команде, игроку.
    \item Реализовать систему логирования действий пользователя в файл с временными метками.
    \item Обеспечить обработку ошибок ввода и некорректных данных.
    \item Покрыть ключевые вычислительные функции тестами свойств с использованием QuickCheck.
    \item Написать отчёт и защитить курсовой проект.
\end{enumerate}

\addcontentsline{toc}{subsection}{3.3. Исходные данные}
\subsection*{3.3. Исходные данные}

Исходными данными для проведения работы являются CSV-файлы из открытого репозитория \textit{NBA-Data-2010-2024} (автор: NocturneBear), доступного по адресу:
\href{https://github.com/NocturneBear/NBA-Data-2010-2024}{https://github.com/NocturneBear/NBA-Data-2010-2024}.

Датасет содержит данные о регулярных сезонах и плей-офф НБА за 2010--2024 годы и включает следующие файлы:

\begin{itemize}
    \item \texttt{regular\_season\_box\_scores\_2010\_2024\_part\_1/2/3.csv} — подробная статистика каждого игрока в каждом матче регулярного сезона: поля \texttt{season\_year}, \texttt{game\_date}, \texttt{gameId}, \texttt{teamName}, \texttt{personName}, \texttt{position}, \texttt{minutes}, \texttt{fieldGoalsMade}, \texttt{fieldGoalsAttempted}, \texttt{fieldGoalsPercentage}, \texttt{threePointersMade}, \texttt{threePointersPercentage}, \texttt{freeThrowsPercentage}, \texttt{reboundsTotal}, \texttt{assists}, \texttt{steals}, \texttt{blocks}, \texttt{turnovers}, \texttt{points}, \texttt{plusMinusPoints};

    \item \texttt{play\_off\_box\_scores\_2010\_2024.csv} — аналогичная статистика для матчей плей-офф;

    \item \texttt{regular\_season\_totals\_2010\_2024.csv} — агрегированная командная статистика за матч: поля \texttt{TEAM\_NAME}, \texttt{GAME\_DATE}, \texttt{MATCHUP}, \texttt{WL}, \texttt{PTS}, \texttt{FG\_PCT}, \texttt{REB}, \texttt{AST}, \texttt{PLUS\_MINUS} и другие;

    \item \texttt{play\_off\_totals\_2010\_2024.csv} — аналогичная командная статистика для плей-офф.
\end{itemize}

Дополнительным входным файлом является конфигурационный файл \texttt{config.json}, задающий параметры сессии: выбранный сезон, тип турнира (регулярный сезон или плей-офф), фильтры по команде и минимальное количество сыгранных матчей.

\section*{4. Основное содержание работы}

\addcontentsline{toc}{subsection}{4.1. Разработка проекта}
\subsection*{4.1. Разработка проекта}

В рамках курсового проекта разрабатывается консольное приложение на языке Haskell с использованием системы сборки Stack. Проект организован в виде следующих программных модулей:

\begin{itemize}
    \item \texttt{Parser} — чтение CSV-файлов (box scores и totals), разбор и валидация конфигурации JSON;
    \item \texttt{Types} — определение типов данных: \texttt{PlayerGame}, \texttt{TeamGame}, \texttt{Config} и других;
    \item \texttt{Stats} — математические функции: среднее, медиана, стандартное отклонение, PER, коэффициент Пифагора, нормализация;
    \item \texttt{Filter} — фильтрация и сортировка записей по параметрам пользователя;
    \item \texttt{Report} — формирование текстовых отчётов и экспорт результатов в файлы;
    \item \texttt{Logger} — запись действий пользователя в \texttt{session.log};
    \item \texttt{UI} — консольное меню и обработка пользовательского ввода.
\end{itemize}

\addcontentsline{toc}{subsection}{4.2. Отчётная документация}
\subsection*{4.2. Отчётная документация}

По результатам работы формируется отчёт, включающий настоящее техническое задание, описание архитектуры и диаграмму типов и модулей, описание технических особенностей реализации, примеры работы программы, руководство пользователя, список литературы (не менее 5 источников) и приложение с исходным кодом.

\addcontentsline{toc}{subsection}{5.4. Функциональные требования}
\subsection*{5.4. Функциональные требования}

\begin{enumerate}

    \item \textbf{Загрузка данных.} Программа читает и объединяет CSV-файлы датасета, валидирует типы и диапазоны значений, выводит информативные сообщения при ошибках парсинга.

    \item \textbf{Топ игроков по показателю.} По выбранному числовому полю (\texttt{points}, \texttt{reboundsTotal}, \texttt{assists} и др.) за указанный сезон программа вычисляет среднее по каждому игроку и выводит ранжированный список. Среднее считается по формуле:
    \[
        \bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i
    \]
    Пример: топ-5 игроков по средним очкам за сезон 2023 из \texttt{regular\_season\_box\_scores}.

    \item \textbf{Профиль игрока по сезонам.} Для выбранного игрока программа агрегирует статистику по каждому сезону и дополнительно вычисляет упрощённый рейтинг эффективности (PER):
    \[
        PER = \frac{PTS + REB + AST + STL + BLK - TOV - (FGA - FGM) - (FTA - FTM)}{MIN} \times 36
    \]
    где все поля берутся из \texttt{box\_scores}. Итоговый PER за сезон — среднее по всем матчам игрока.

    \item \textbf{Сравнение двух игроков.} Программа нормализует показатели обоих игроков относительно всей лиги по формуле min-max и выводит их рядом:
    \[
        x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \in [0,\,1]
    \]
    Пример: сравнение Curry и Lillard по очкам, передачам, 3P\% и PER за сезон 2022.

    \item \textbf{Рейтинг команд по коэффициенту Пифагора.} По данным \texttt{regular\_season\_totals} (поля \texttt{PTS} и \texttt{PLUS\_MINUS}) программа вычисляет ожидаемый процент побед каждой команды:
    \[
        W\% = \frac{PF^{\,e}}{PF^{\,e} + PA^{\,e}}, \quad e = 13{,}91
    \]
    и сравнивает его с реальным. Разница указывает на «везение» или «невезение» команды в сезоне.

    \item \textbf{Плей-офф против регулярного сезона.} Для выбранного игрока программа считает средние по \texttt{regular\_season\_box\_scores} и \texttt{play\_off\_box\_scores} раздельно и выводит дельту по каждому показателю:
    \[
        \Delta = \bar{x}_{\text{playoff}} - \bar{x}_{\text{regular}}
    \]
    Пример: Nikola Jokic, сезон 2023 — рост по очкам $\Delta = +5{,}7$, по подборам $\Delta = +1{,}3$.

    \item \textbf{Статистическая сводка по позициям.} По выбранному полю программа группирует игроков по позиции (\texttt{position}) и для каждой группы вычисляет среднее, медиану и стандартное отклонение:
    \[
        \sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2}
    \]
    Пример: распределение очков по позициям PG / SG / SF / PF / C за сезон 2022.

    \item \textbf{Лучшие матчи игрока.} Фильтрация строк \texttt{box\_scores} по имени игрока с сортировкой по выбранному показателю и постраничным выводом: дата, соперник, статистика матча, результат (W/L).

    \item \textbf{Экспорт результатов.} Сохранение отчёта по игроку или команде в \texttt{report.txt}; экспорт топ-листа в \texttt{top\_players.csv}.

    \item \textbf{Логирование.} Запись всех действий пользователя в \texttt{session.log} в формате \texttt{[YYYY-MM-DD HH:MM:SS] action: ...}

    \item \textbf{Обработка ошибок.} Корректная обработка отсутствующих файлов, пустых полей, деления на ноль и неверного ввода без аварийного завершения программы.

    \item \textbf{Тестирование свойств (QuickCheck):}
    \begin{itemize}
        \item монотонность: сортировка по рейтингу даёт неубывающую последовательность;
        \item корректность нормализации: все значения после нормализации лежат в $[0,\,1]$;
        \item симметрия среднего: перестановка элементов не меняет результат;
        \item устойчивость к граничным случаям: пустой список, нулевые значения, все элементы одинаковы.
    \end{itemize}

\end{enumerate}

\addcontentsline{toc}{subsection}{5.5. Требования к средствам разработки}
\subsection*{5.5. Требования к средствам разработки}

При разработке программного обеспечения должны преимущественно использоваться стандартные средства и существующие библиотечные решения:

\begin{itemize}

\end{itemize}

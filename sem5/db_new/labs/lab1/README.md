# Запросы для лабораторной

## Запрос для View
для каждого автомобиля подсчитать количество тревожных событий и число парковочных зон, в которых этот автомобиль парковался.

## Запрос Простой
Вывести автомобили, которые парковались более чем в N разных зонах и имеют хотя бы одно тревожное событие.

## Запрос Сложный
Вывести автомобили, которые парковались менее чем в N разных зонах и имеют необработанные тревожные события заданного типа

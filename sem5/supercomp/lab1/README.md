# BF16 CLI

Небольшая консольная программа для преобразования чисел в формат `bfloat16`
(BF16) и обратно. Используется стандартная библиотека Python: число сначала
представляется как `float32`, затем его младшие 16 бит округляются по правилу
«до ближайшего чётного».

## Запуск

Из папки `sem5/supercomp/lab1`:

```bash
python3 bf16_cli.py to-bf16 3.14159
# 0x4049
# 0100000001001001

python3 bf16_cli.py from-bf16 0x4049
# 3.140625
# 0100000001001001
```

Первый аргумент — направление преобразования:

- `to-bf16` — десятичное число в 16-битное представление BF16 в hex;
- `from-bf16` — 16-битное представление BF16 (`0x0000`–`0xFFFF`) в число.

# Лабораторная работа 3

Демонстрационные материалы к работе «Пользовательское окружение. Пользовательский профиль».

## Запуск демонстрации

```sh
bash ./lab3/demo.sh
```

Скрипт показывает текущие `PATH`, `LANG`, `TERM`, `PS1` и демонстрирует
временную очистку `PATH`, а также установку `LANG` и `TERM=vt100`. Изменения
переменных выполняются внутри дочерних subshell и не сохраняются в текущее
окружение. Выбранная локаль зависит от системы; её можно задать для
демонстрации, например:

```sh
LAB3_LANG=ru_RU.UTF-8 bash ./lab3/demo.sh
```

## Примеры для упражнений

- [bash_profile.example](./bash_profile.example) — пример настроек login shell.
- [bashrc.example](./bashrc.example) — пример интерактивного приглашения.
- [prompt.sh](./prompt.sh) — выполнить `source ./lab3/prompt.sh`, чтобы
  временно изменить приглашение текущего Bash. `PS1` не меняется запуском
  скрипта как отдельного процесса.
- [plan.example](./plan.example) — пример содержимого файла `.plan`.

Чтобы посмотреть, как установленный `finger` отображает `.plan`, скопируйте
пример в домашний каталог своей учебной Linux-системы и выполните команду:

```sh
cp ./lab3/plan.example "$HOME/.plan"
finger "$USER"
```

Команда `finger` может отсутствовать в системе; для этого опыта она должна
быть установлена.

Значения `PATH`, `LANG` и `TERM` на компьютерах различаются. Для отчёта
зафиксируйте вывод `env` и `set` в своей системе. После опыта с пустым
`PATH` восстановите записанное исходное значение; после опыта с `TERM`
верните прежнее значение или закройте временный терминал. Для наблюдения
изменения локали выбирайте только установленное значение `LANG`.
